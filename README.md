# Terra Pulse website

A responsive front-end prototype built with Tailwind CSS (CDN), HTML, and vanilla JavaScript.

## Run it
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. For the best experience in VS Code, install/use Live Server and choose **Open with Live Server**.

## Included interactions
- Responsive desktop/mobile navigation
- Location search demo
- Environmental category selection
- Toggle map layers
- Zoom illustration in/out
- Before/after comparison labels
- Location / file-upload tab
- Demo analysis toast
- Downloadable CSV demo report
- Demo modal and help guide

## Important
The map is an illustrative SVG and all analysis is demo-only. This prototype does not connect to live satellite imagery, geocoding, user accounts, or AI analysis. Those require real data providers and a backend.
